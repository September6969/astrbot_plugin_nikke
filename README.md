# NIKKE 综合助手

面向 AstrBot + NapCat/OneBot 的 NIKKE 插件，提供 BlaBlaLink 账号查询、角色练度卡、联盟突袭战况、活动日程和个人截止提醒。当前为早期测试版。

[安装与首次使用](#安装与首次使用) · [常用命令](#常用命令) · [日程与订阅](#日程与订阅) · [配置](#配置) · [常见问题](#常见问题)

## 仓库导航

[文档总览](docs/README.md) · [开发工具](scripts/README.md) · [结构与迁移](docs/architecture/REPOSITORY_ORGANIZATION.md) · [历史资料](docs/archive/INDEX.md)

业务代码保持 `adapters/`、`application/`、`core/`、`features/`、`integrations/`、`ui/` 分层；内置素材在 `assets/`，模板在 `templates/`。独立组件位于 `extension/`、`runtime/spine_worker/` 和 `deploy/`，本地工具输出进入已忽略的 `output/`。

## 能做什么

| 功能 | 说明 |
|---|---|
| 账号绑定 | Chrome／Edge 扩展辅助绑定；密码和验证码只提交给 BlaBlaLink 官网 |
| 个人资料 | 查询等级、战力、同步器、前哨、主线等账号信息 |
| 角色练度 | 查看练度总表、单角色技能、装备和属性；单卡采用白色竖版布局与 Spine 立绘 |
| 联盟突袭 | 一张卡查看 Boss 进度、贡献前五与个人摘要；排行和队伍记录支持分页 |
| 活动日程 | 整合 GameKee 与官方公告，展示进行中及即将开始的活动，使用缓存活动图作背景 |
| 截止订阅 | 自选类型，结束前 24 小时内提醒一次；群内只 @订阅者 |
| 公开资料 | 公告、塔层静态速查、本地授权攻略和塔罗功能 |
| 可选日常 | 签到、领奖、CDK 兑换、账号汇总及语音；部分功能需要额外开关或资源 |

账号查询需要绑定；公开日程、日程订阅、公告和塔层速查无需绑定。日程来自可获取的来源，不保证覆盖游戏内全部活动；突袭统计以卡片标注的数据范围为准。

## 安装与首次使用

### 环境要求

- AstrBot `>=4.24,<5`，Python `>=3.12`。
- NapCat／OneBot（`aiocqhttp`）适配器；主动通知需要宿主支持会话消息发送。
- 可访问 BlaBlaLink、官方公告与活动数据来源的网络。
- 使用账号绑定时，需要 HTTPS 域名和反向代理。

### 安装插件

1. 将仓库目录放入 `AstrBot/data/plugins/astrbot_plugin_nikke`。
2. 在 AstrBot 所用的 Python 环境安装 `requirements.txt`，然后重启 AstrBot。
3. 持久化 `AstrBot/data/nikke`。账号数据库与 `secret.key` 必须一起备份。
4. 在插件配置中将 `public_base_url` 改成自己的 HTTPS 站点地址。
5. 将域名反向代理到插件的容器内端口 `6210`。

仓库提供 [Caddy 示例](deploy/Caddyfile)和 [Docker Compose 示例](deploy/docker-compose.caddy.yml)。Caddy 与 AstrBot 必须在同一 Docker 网络；不向公网直接开放 `6210`、AstrBot 后台或 NapCat 后台。

```caddyfile
nikke.example.com {
    reverse_proxy astrbot:6210
}
```

示例中的 `astrbot` 应替换为实际可解析的服务名。不要记录包含一次性绑定令牌的完整访问 URL；反向代理配置详见 [Caddy 验收说明](docs/acceptance/CADDY_ACCEPTANCE.md)。

### 开始使用

- 发送 `/妮姬 帮助` 查看命令；可先用 `/妮姬 日程` 查看公开活动。
- 需要查询账号时，私聊发送 `/妮姬 账号 绑定`，按绑定页面提示操作。
- 自建站点的扩展应从自己的 `https://站点域名/download` 下载；更改 `public_base_url` 后，重启插件并重新安装扩展。
- 绑定后发送 `/妮姬 我的` 或 `/妮姬 查询 练度`。

不要向机器人发送 Cookie、密码、验证码，也不要转发绑定链接。默认不允许在群里生成绑定链接。

## 常用命令

`[参数]` 表示可选，`<参数>` 表示必填。中文命令也支持 `#妮姬` 前缀；旧版 `/nikke` 命令继续兼容。

### 账号与查询

| 命令 | 用途 |
|---|---|
| `/妮姬 帮助 [账号\|查询\|日常]` | 分类帮助 |
| `/妮姬 账号` | 查看绑定状态 |
| `/妮姬 账号 绑定` | 创建绑定链接，默认仅私聊 |
| `/妮姬 账号 解绑` | 解除自己的绑定 |
| `/妮姬 账号 汇总 开` 或 `关` | 设置自己的账号汇总偏好 |
| `/妮姬 我的` | 指挥官资料 |
| `/妮姬 查询 练度 [角色名]` | 练度总表或单角色卡 |
| `/妮姬 查询 资料 <角色名>` | 角色基础资料 |
| `/妮姬 战役 46-14A-1` | 指定关卡通关记录 |
| `/妮姬 塔层 极乐净土 1` | 塔层静态资料，不代表玩家进度 |
| `/妮姬 攻略 练度 2` | 本地授权攻略索引分页 |
| `/妮姬 塔罗 [单抽\|三张\|今日\|状态]` | 塔罗功能 |

### 联盟突袭

| 命令 | 用途 |
|---|---|
| `/妮姬 突袭` | Boss 进度、贡献前五与个人摘要 |
| `/妮姬 突袭 排名 [页码]` | 贡献排行，每页 15 人 |
| `/妮姬 突袭 我的 [页码]` | 个人队伍记录，每页 5 条 |

保留 `/妮姬 联盟突袭` 和英文别名。贡献比例只针对相同范围内已返回的伤害计算；历史记录标注赛季，队伍记录按游戏日分组。名单或攻击范围不完整时，不判断谁未出刀，也不根据记录数推断剩余刀数。部分接口失败时保留其他有效区域。

### 公告与日常

| 命令 | 用途 |
|---|---|
| `/妮姬 公告` | 查看公开公告 |
| `/妮姬 公告 语言 en` | 按语言查询，支持 en／ja／ko／th／de／fr |
| `/妮姬 公告 分类 活动` | 按分类查询 |
| `/妮姬 公告 搜索 <关键词>` | 搜索公告 |
| `/妮姬 公告 诊断` | 本地只读诊断 |
| `/妮姬 签到 状态` | 查询状态，不提交签到 |
| `/妮姬 签到` | 签到，需要启用对应写操作 |
| `/妮姬 日常` 或 `/nikke daily` | 社区签到，并领取已达成的免费新手任务奖励 |
| `/妮姬 日常 状态` | 只读查询签到、奖励和最近执行结果 |
| `/妮姬 日常 自动 开` 或 `关` | 设置本人的自动签到与免费领奖 |
| `/妮姬 兑换 <CDK>` | 国际服 CDK 兑换，需要开启兑换功能 |
| `/妮姬 兑换 批量 <CDK1> <CDK2>...` | 批量兑换 |
| `/妮姬 兑换 可用` 或 `历史` | 查看兑换相关记录 |
| `/妮姬 语音 开` 或 `关` | 设置自己的语音偏好 |
| `/妮姬 语音 语言 en` | 设置语音语言 |
| `/妮姬 语音 角色 rapi` | 设置语音角色 |

## 日程与订阅

### 查看日程

- `/妮姬 日程 [7|14|30] [页码]`：默认未来 14 天、第一页，每次返回一页。
- `/妮姬 日程 刷新`：刷新公告与活动来源；失败时保留旧快照，并提示数据状态。

日程范围包括：协同作战、个人／联盟突袭、常规限时活动（标作“支线”，包括剧情和联动活动）、Pick Up、月度／活动 Pass、转盘时装、限时双倍、维护、签到和免费获取。Story 1／Story 2／Hard 保留所属活动名称，两个同时开放的活动分别展示。

普通限时时装、情报宣传页、礼包、角色临时试用等不展示。固定玩法用中文，活动和角色专名保留原名；未公布的时间不推算。活动图下载失败时使用备用背景，不影响已有日程查询。

### 订阅截止提醒

| 操作 | 命令 |
|---|---|
| 查看可选类型，不直接开通 | `/妮姬 日程 订阅` |
| 开通或替换所选类型 | `/妮姬 日程 订阅 协同,个人突袭,签到` |
| 分别选择两类 Pass | `/妮姬 日程 订阅 月度Pass,活动Pass` |
| 查看当前设置 | `/妮姬 日程 订阅状态` |
| 取消提醒 | `/妮姬 日程 取消订阅` |

可选类型：**协同、个人突袭、联盟突袭、支线、招募、月度Pass、活动Pass、转盘、双倍、维护、签到、免费**。`Pass` 同时选择两类通行证。多个类型用逗号分隔，再次提交列表会替换原有选择。

- 设置只作用于当前会话里的本人；各群聊、私聊及不同用户互不影响。
- 默认在结束前 **24 小时内**检查并提醒，每期事件一次。群内只 @订阅者，私聊直接通知。
- 订阅时已不足 24 小时的未结束事件，在下一轮检查时提醒。设置和去重记录重启后保留；不补发已经结束的事件。
- 仅对新鲜、同步无错误、截止时间明确且仍进行中的日程发送提醒。来源异常、数据过期、活动取消或时间不明时暂停通知。
- 发送结果不确定时不自动重发，避免重复 @。没有收到提醒不代表游戏内没有活动。

个人日程订阅无需管理员权限或账号绑定，**不依赖 `enable_announcement_push`**。当前已通过模拟发送器和 @组件测试，真实会话主动通知仍需部署后现场验收。

### 管理员公告订阅

`/妮姬 公告 订阅` 和 `/妮姬 公告 取消订阅` 仅供机器人管理员管理当前会话。必须额外开启 `enable_announcement_push`，其公告及截止提醒使用旧有的 24／6／1 小时规则，与上述个人日程订阅分别管理。

公告查询、诊断、日程查询与显式刷新本身不主动推送消息。管理员可用 `/妮姬 公告 深度刷新 [语言]` 重扫公开来源。

## 配置

在 AstrBot 插件配置页修改。完整字段见 [_conf_schema.json](_conf_schema.json) 和 [配置合同](docs/acceptance/CONFIGURATION_ACCEPTANCE.md)。

| 配置 | 默认值 | 用途 |
|---|---|---|
| `public_base_url` | 仓库预设站点 | 自建时必须改为自己的 HTTPS 站点；不带路径或查询参数 |
| `web_host` / `web_port` | `0.0.0.0` / `6210` | 绑定服务监听地址，经反向代理对外提供服务 |
| `allow_group_bind` | `false` | 允许群内生成绑定链接，仅适合可信群 |
| `enable_daily_actions` | `false` | 签到与领奖写操作总开关 |
| `enable_cdk_redemption` | `false` | 国际服 CDK 兑换开关 |
| `enable_announcement_push` | `false` | 管理员已订阅会话的公告推送开关 |
| `daily_hour` / `daily_minute` | `8` / `10` | 每日任务时间，北京时间 |
| `summary_hour` / `summary_minute` | `8` / `30` | 汇总时间，北京时间 |
| `request_timeout` | `20` | BlaBlaLink 请求超时秒数 |
| `max_concurrency` | `2` | 账号任务最大并发数 |
| `spine_worker_path` / `spine_worker_path_4_1` | 空 | 对应版本的 Spine worker 路径 |
| `custom_character_aliases` | 空 | 自定义角色别名 |

所有图片页面统一使用 T2I；渲染失败时从同一次查询结果生成文字回退，不重复读取数据。旧版本保存的 `ui_renderer` 配置会被忽略并统一到 T2I，插件不再公开此开关。Pillow 仍用于本地图片素材处理。迁移路径与验收边界见 [渲染器迁移说明](docs/ui/RENDERER_MIGRATION.md)。

社区日常按 UTC 零点（北京时间08:00）刷新，默认08:10执行，重启错过时刻后可补跑。本人须开启 `/妮姬 日常 自动 开`；旧偏好仅签到，重新开启才增加免费领奖。自动执行不依赖群汇总，成功静默，仅异常私聊一次；请私聊使用日常命令登记通知会话。无私聊路由时可用状态命令查结果。

所有写操作仍受全局开关控制。免费领奖目前覆盖官方新手任务，不代做点赞、浏览或关注，不花积分兑换月度奖励。新增领奖尚未真实账号验收；官方合同、历史签到证据与本轮测试边界见[社区日常说明](docs/operations/COMMUNITY_DAILY_COMPLETION.md)。

管理员可用 `/妮姬 管理 健康` 查看只读健康状态；其他管理命令见 `/妮姬 帮助 管理`。

## 常见问题

### 绑定失败或提示 `MetaData no user account`

先确认 BlaBlaLink 官网个人页能看到 NIKKE 账号信息，再从自己的绑定站点重新安装扩展并创建新链接。扩展只读取目标网站实际使用的 Cookie 与必要请求头，不读取密码或请求体。

维护者应检查域名、HTTPS、反向代理和容器网络。`https://站点域名/healthz` 仅在数据库和密钥同时存在时返回健康状态。不要为排障关闭证书校验，也不要要求用户发送 Cookie 或导出凭据。

### 日程没有提醒

先在原订阅会话发送 `/妮姬 日程 订阅状态`，确认所选类型。再检查事件是否进入结束前 24 小时、日程是否过期或同步失败，以及宿主是否允许主动发送消息。事件已提醒、已结束、取消或截止时间不明确时不会再通知。

### 图片缺失或只显示占位图

日程背景依赖活动图缓存，下载失败时显示备用背景。角色卡立绘依赖匹配版本的 Spine worker 与资源；缺失、超时或运行时不可用时显示中性占位图。单角色卡渲染失败时明确提示，不回退成旧式角色卡。

### 查询数据不完整

上游接口、来源覆盖和登录状态均可能影响结果。请以卡片的数据范围、更新时间和错误提示为准。突袭排行不是完整赛季榜单；塔层资料不是玩家实际进度或通关保证。登录失效时重新绑定。

### 迁移后账号无法解密

必须同时迁移 `data/nikke/nikke.sqlite3` 和 `data/nikke/secret.key`，并限制密钥文件权限。丢失密钥后旧 Cookie 无法恢复，需要重新绑定。

从插件父目录执行备份：

```bash
python -m astrbot_plugin_nikke.scripts.backup_nikke_data \
  --data-dir AstrBot/data/nikke \
  --destination /安全的备份目录
```

备份工具只读、不连接网络；拒绝符号链接、数据目录内的备份目标及已有目标覆盖。恢复前检查备份与权限。升级或回滚前，可在插件目录执行：

```bash
python scripts/operations/upgrade_preflight.py --data-dir /实际路径/AstrBot/data/nikke
```

此检查不修改数据库或生产文件。启动时会执行兼容的数据库迁移；更高版本的数据结构会被拒绝加载，不会自动降级。

## 安全与使用边界

- 不保存账号密码；Cookie 加密存储，绑定令牌十分钟有效且仅可使用一次。
- 扩展权限限于 BlaBlaLink 与配置的绑定站点；绑定服务只接受目标域 Cookie 并限制大小。
- 日志与诊断不应输出 Cookie、令牌、授权头或完整账号凭据。
- 独立技能、面谈、关卡／企业塔详情、魔方／收藏品查询、通用素材／JSON 导出及任意历史赛季突袭查询仍有开发缺口，详见[开发完成度核对](docs/operations/DEVELOPMENT_GAPS_20261013.md)。自动点赞、关注和资料修改未实现。
- 攻略与语音只使用有权使用的资源；不复制未经授权的第三方攻略正文。Spine 资源和运行时许可由部署者核实。
