# 立绘与锚点联动验证

日期：2026-10-08。实现基线：`0608c2c`，分支：`fix/spine-anchor-linkage`。

## 问题与修改

Raven（`c851`）已能生成立绘，但线上预计算锚点表没有其记录，因此进入 `anchor_unavailable` 整图缩放。长剑和飘带占据图片宽度，压缩了人物在卡片中的占比。

本次在官方 worker 的实际绘制帧导出可见附件边界与活动骨骼坐标。Python 使用真实裁切偏移换算坐标，将识别结果、图片尺寸及 RGBA SHA-256 一起写入 PNG 元数据。像素和锚点通过一次临时文件替换发布，不另外维护可能失配的 sidecar。

- 新生成的本地与上游运行时立绘自动附带锚点。
- 运行时旧缓存缺少有效记录时，走既有去重、锁和 deadline 补生成路径；成功后持久化，重启可直接复用。
- 无法提取的结果也记录原因，避免每次请求都重复补算；补算失败时保留已有可显示缓存。
- 卡片仍优先采用与像素匹配的既有预计算记录；缺失时读取图片随附记录，损坏或指纹不匹配的记录不会被使用。
- 更新运行时立绘及整卡缓存版本，避免旧小人物卡片遮蔽新结果。
- Raven 的胸部骨骼名带 `_ww` 后缀。新增严格的左右胸部附件配对回退：名字必须有明确胸部语义、左右各唯一、同父骨骼；歧义时拒绝推断，不按编号猜测骨骼。

本次沿用现有脸部尺寸与头胸安全区构图，没有全局切换为固定眼胸距离公式。已有 bundled 图片的优先级保持不变。
