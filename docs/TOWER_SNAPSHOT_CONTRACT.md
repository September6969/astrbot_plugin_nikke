# 塔层静态快照合同

`/妮姬 塔层 <塔名> <层数>` 只读取仓库内置的静态快照；它不读取账号、不会推断玩家进度，也不承诺可以通关。

## 必需元数据

- `source`：非空且没有首尾空白的来源标识。
- `retrieved_at`：严格 `YYYY-MM-DD` 日期。
- `normalized_source_sha256`：小写、64 位十六进制 SHA-256 文本；它标识采集时的规范化来源，不在运行时重新请求网络验证。
- `floors`：非空且最多 20,000 条的对象。

每个键必须是 `tribe|elysion|missilis|tetra|pilgrim:<1..10000>`，没有前导零。每条记录必须包含唯一的正整数 `stage_id` 和正整数 `standard_battle_power`。未知键不会推断其他层或战力。

## 失败语义

损坏、过大或字段不符合合同的快照在加载时拒绝；命令层返回“塔层静态资料暂不可用”，而不是显示局部或猜测数据。输入的塔层号同样要求无符号、无前导零的十进制正整数。

## 证据边界

测试覆盖内置快照和合成损坏快照。它不证明来源仍在线、数据最新、资源授权，或真实账号的塔层进度。
