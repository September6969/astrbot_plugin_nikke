# 模型支持范围

实现提供有限候选搜索与解释性排序。模板克制声明归为 community，完整爆裂轴归为 mechanic，速度及排序规则归为参考参数或 heuristic。所有证据保留来源、版本、可信度和缺失字段。

## 已支持

- P1–P5 同阶段角色的启动顺序。
- 蒂亚、冬日露菲、阿维斯塔、兔女郎爱丽丝的再入 B1。
- 超级巨星阿妮斯在另一位普通 B1 存在时的条件再入。
- 拉毗小红帽在没有 B1 时的阶段转换。
- 毒蛇珍藏的再入 B2。
- 普通与珍藏基础身份互斥，单队五人及三队十五人去重。
- 来源锁定的静态 RL 充能曲线，缺少任一角色参数时返回 unknown。
- 三种三队相对排序目标，候选和时间预算截断。

## 尚待验证

全阶段角色连续自动爆裂、角色冷却、再入的具体时间、连结受击回充、穿透、多目标命中、超频、魔方及个人技能等级尚未纳入完整战斗推演。全阶段角色承担缺失阶段时返回不完整轴，避免产生未经验证的连续启动序列。

参数基于来源快照。静态充能领先不等价于当前游戏环境下更早完成全爆裂。涉及再入时暂停静态速度差的排序加分。

模板可能同时给出有利和不利声明，两类证据均保留。模板候选搜索会截断，三队无解只表示当前候选池和预算内无解。

授权统计按攻守双方较低的同角色同站位数分为 5/5、4/5、3/5，只展示最接近一档的胜负与 Wilson 95% 区间，并标出相似样本的差异位置。相似档合并了差异位角色不同的多组攻守组合，文案会写明合并组数，并说明不代表本阵容或本对手的实测胜率。只查最终展示的方案，历史证据不调整当前模型排序。每场只计入原始攻守方向一次，镜像阵容也只计一次。混合攻守的旧版快照需要重新同步。跨补丁校准属于后续增量。unknown 补丁与过期快照均有提示。

可选 P7 的逐帧模拟与个人配置增强按原计划留待后续版本。
