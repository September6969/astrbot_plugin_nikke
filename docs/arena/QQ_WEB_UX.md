# QQ 与网页交互合同

## 文本

统一命令注册保留 command、arg1、arg2、arg3。Arena 分支验证原始消息的命令前缀、竞技场子命令及动作名后，读取完整剩余文本。支持中文全角空白、全角斜线、顿号、逗号及换行。英文角色名内部空格被保留。数字、资源号和受控别名由既有身份解析器处理。

serv 上的 AstrBot 4.27.5 使用实际 `CommandFilter` 解析模拟事件，再用解析后的参数调用插件。中文全角空格和全角斜线、英文入口、三行十五人的文字导入均得到预期结果。模拟事件使用唤醒阶段去除命令前缀后的消息形态。

一条五人文本按 P1–P5 解析。未知和歧义名称返回候选，部分名称不会直接执行。输入超过 1000 字或含重复基础角色时返回可修改错误。

群内仅输出公开沙盒结果。个人名单、编辑链接及本人网页结果均在私聊读取。

## 网页

点击 QQ 链接只打开公开引导页。主动点击进入后，以同源 Fetch POST 兑换，浏览器转到固定 /arena/edit。无 JavaScript 时引导用户回 QQ 使用文字解队。

编辑页采用横排 P1–P5 与常驻头像名册。点站位后可搜索别名、按 B1 至 B3 筛选，选中角色后自动跳到下一空位。桌面并列显示排阵和名册，手机用队伍标签切换并固定分析入口。换位先选择起点，再点同队或其他队伍目标。仍支持撤销、清空和批量导入。重复及缺位时禁用分析。手动选择持有、已绑定持有和沙盒为显式模式。分析和会话结果保存由服务端执行。

启用有效历史快照时，头像名册按所选赛事的对位出场次数排列，次数相同时及未入样本的角色按模板常见度排列。仅使用模板时，先比较主选出现次数，再比较候选出现次数，同一模板对同一角色只计一次。别名搜索和爆裂筛选保留排序。

三队模式下展开「加入我方候选」，可以为每场粘贴一队并保存。手动队按当前持有范围和爆裂链校验，与自动候选一起参与排序。最终三队使用不同角色；手动队缺少模板评分时按已知静态机制比较。

以下阵容已在 320 px 浏览器视口完成三队粘贴、分析和刷新回查。

```text
红莲/豺狼/布兰儿/桑迪/特蕾娜
丽塔/麦斯威尔：平凡技师/尼恩：透视之眼/拉普拉斯/德雷克
N102/安妮：奇迹仙女/麦斯威尔/拉普拉斯：究极英雄/德雷克：终极反派
```

草稿保存在服务端并带递增 revision，刷新后恢复。编辑页合并等待中的修改，断网后可在原页重试。上一版本提交的草稿与已保存内容完全相同时，重试会返回当前版本。另一页面提交了不同草稿时返回 409。分析重试沿用原幂等键，同键不同阵容返回 409。

分析按钮附近显示等待、超时与会话失效状态。单次请求等待超过 25 秒时可重试。结束编辑会话需要再次确认，会话结束后可回 QQ 获取新链接或回查先前结果。

## 本轮浏览器证据

Playwright 使用 Edge，在 320×800 和 430×860 CSS px 下验证。单队和十五人三队均完成导入、分析及刷新恢复。320px 下 document.scrollWidth 等于 innerWidth，所有可见按钮高度均至少 44px。浏览器控制台未出现编辑脚本错误。
