# Web 安全验收

## 边界

竞技场接口全部位于 /arena。独立中间件覆盖该前缀，优先包裹绑定站点中间件。绑定站点已有的 60 次每分钟每 IP 限制继续执行，竞技场会话另有 30 次每分钟的 API 限额。

## 已自动验证

- 引导页 GET 不读取 actor_id、不兑换 token。重复预览仍可兑换。
- 链接与 Cookie 均使用 32 随机字节，服务端只索引其 SHA-256。
- 首次进入期限 15 分钟，兑换后重放失败。
- 独立 Cookie 使用 Secure、HttpOnly、SameSite=Lax 和 /arena 路径。
- 修改操作需要精确站点 Origin。拒绝空 Origin、其他站点及扩展 Origin。
- 兑换后修改操作另需 X-Arena-CSRF 与服务端会话中的随机值一致。
- 草稿及分析只接受白名单字段、已知角色和一队或三队五槽。请求体上限沿用 64 KiB。
- 拒绝前端提供 actor_id。名单、草稿和结果从 Cookie 对应会话取所属人。
- 幂等键相同且输入一致时复用原结果，同键异输入返回 409。
- 会话闲置 30 分钟或绝对 60 分钟到期。本人结果两小时清理。
- 令牌、会话和结果存储均有 128 项容量上限。每会话最多保留 16 个幂等提交结果。
- 关闭 Web 开关时清空旧会话及结果，基础文字计算仍独立工作。
- 进程重启后内存会话安全失效。共享 Web app 清理时释放 Arena 会话。
- 所有 Arena 响应带 no-store、no-referrer、nosniff 及严格 CSP。
- 页面仅加载同源脚本和样式，通过 textContent 放入角色名与结果。
- 头像从既有本地资源读取，缺图退为姓名，无 Spine 或外部头像请求。

## 部署检查

公网入口必须使用既有 HTTPS 站点。代理应隐藏 /arena/open/ 后面的令牌并禁用查询及请求体日志。插件 aiohttp 访问日志已经关闭。

直连插件的 Caddy 使用可预期的容器地址时，在插件配置中设置 `web_trusted_proxy_ip` 为该地址。仅当 TCP 对端与配置匹配才读取 Caddy 追加的最后一个 `X-Forwarded-For` 地址。留空或透传地址无效时使用 TCP 对端 IP。Caddy 保持默认的请求转发头处理行为。

在 serv 的隔离环境使用生产同镜像 Caddy、独立本地 CA 和回环端口，验证 HTTPS 预览、兑换、防重放、Secure Cookie 自动回传、名单读取、分析和本人回查。定向限流测试验证可信代理拆分访客配额，以及非可信直连无法通过请求头改变配额。生产公网的预览、无会话拒绝及链接路径日志已核对。QQ 内置 WebView 按本轮约定留作实机补验。

生产启用了站点访问日志。2026-11-17 21:03 PST 在本地 `deploy/Caddyfile` 示例及 serv 的生产配置写入 `log_skip /arena/open/*`。生产使用占位链接验证路径未出现在 Caddy 日志，同一轮的普通健康请求仍被记录。更改前回看最近一个链接有效期，未发现占位核对之外的竞技场链接访问记录。旧代理配置备份于 部署备份目录。
