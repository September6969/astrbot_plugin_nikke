## 设计约束

原生 Pillow + 原生 HTML/CSS，不引入 UI 框架和远端装饰素材。
近黑石墨画布、炭灰面板、米白正文、冷灰辅助文字、克制琥珀强调。
页面布局变化程度 3/10，动效 1/10，信息密度 6/10。
保留 Noto Sans 中文字体；长文本优先合理分配空间，其次截断，不将主体字号压至不可读。
