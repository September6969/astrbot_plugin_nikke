# 角色技能素材自动同步

角色卡素材预取会按 resource_id 读取官网 roledata/{id}-v2-en.json，确认身份及三个技能图标字段完整后原子保存到运行缓存 character-skills/{id}.json。新角色不再受内置 character_weapon_bases.json 的覆盖范围限制。

缓存24小时有效，过期后在下一次查询复查；失败保留最后有效数据或内置映射，120秒内不重复请求。同实例的并发槽位共用一次元数据请求。离线模式禁止联网。技能图标先读本地，缺失时从官方资源CDN补齐，继续使用既有下载器的图片校验与缓存。

该机制按需更新，不是后台定时全量抓取。角色名称目录仍沿用启动时加载；简体昵称/歧义别名、Spine来源及其下载链路不由此机制更新。它不会进行登录、签到或任何账号写操作。

验证：48项相关测试（8 subtests）通过；真实官方公开数据确认角色19的三个技能图标，并在服务器验证三个WebP均可下载、解码。实际QQ查询图片仍需消息链路验收。
