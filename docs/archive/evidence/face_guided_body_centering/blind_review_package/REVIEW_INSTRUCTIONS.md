# 人工盲审视觉评审指南 (Blind Review Instructions)

本包为 NIKKE 单角色练度卡立绘居中方案的**完全盲审材料**。
请评审人独立审阅各样本卡面，无需任何算法背景知识，不要推测底层实现。

---

## 一、材料清单

1. **盲审卡面看板**: `[render_id]_policy_blind.png`（共 36 份）
   * 每份看板包含 5 张卡面：
     * **`Reference`**: 当前基准构图（标准脸部对齐参考）
     * **`Candidate 1` ~ `Candidate 4`**: 4 种不同候选卡面（顺序已通过确定性哈希随机打散，每个样本顺序各不相同）
2. **打标表单**: `blind_review.csv`
   * 评审人在此表格中逐项填写评价结果。

---

## 二、评审核心原则

评审时，请保持真实卡面的直觉审美，遵循以下由全局到局部的观察层级：

1. **先看人物整体在卡面中的视觉平衡**：
   * 观察立绘主体在 1600×2400 卡面中是否视觉居中、舒适，重心是否失衡或偏斜。
2. **再看头部与 Header / 战力区关系**：
   * 关注头部位置与左上角战力数字、星级、角色名等核心信息组的视觉呼吸感与空间从属关系。
3. **再看躯干视觉中心**：
   * 观察身体核心躯干与下方信息条、技能条及装备区的呼应是否自然协调。
4. **最后看边缘裁切或构图紧张**：
   * 检查左右两侧是否有武器、披风或肢体被异常贴边或不当切断，画面整体是否产生局促感。
5. **不推测算法原理**：
   * 请勿猜测背后是哪种位移算法或平滑截断曲线。
6. **不比较 Candidate 编号之间谁“看起来更保守”**：
   * 各候选编号顺序均为独立随机排列，Candidate 1 并不必然对应特定策略。

---

## 三、打标字段与评价维度

对每个样本的 `Candidate 1` 到 `Candidate 4`，分别在 `blind_review.csv` 中填写三项独立判断：

### 1. 整体观感 (`candidate_N`)
以 `Reference`（基准卡面）为参照：
* **`better`**: 整体构图明显优于 Reference，视觉重心更稳、留白更舒服。
* **`same`**: 与 Reference 在视觉感知上无显著差异。
* **`worse`**: 整体构图劣于 Reference（例如过冲、头部偏离严重、边缘局促）。

### 2. 修正方向 (`candidate_N_direction`)
* **`correct`**: 人物移动方向合理，朝着更居中、更协调的正确方向移动。
* **`neutral`**: 几乎未移动，或无法明确判断有益方向。
* **`wrong`**: 移动方向错误（例如把本来偏右的立绘进一步推向同侧极端）。

### 3. 修正幅度 (`candidate_N_magnitude`)
* **`insufficient`**: 方向正确，但幅度过小，改善效果不明显。
* **`appropriate`**: 幅度恰到好处，既修正了重心，又保持了头部焦点与舒适的构图。
* **`excessive`**: 修正过冲，移动过大导致人物贴边、失衡或信息区割裂。

### 4. 备注 (`candidate_N_note`)
* 可选填写具体观察细节（例如：“右侧披风贴边”、“脸部偏左”、“头部与战力区过于拥挤”等）。
